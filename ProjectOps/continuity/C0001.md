### Hallazgos materiales

#### H1 — ABOS ya tenía bootstrap, no ProjectOps modular

HECHO: existían `AGENTS.md`, `CONTINUITY.md` y `PLAN.md` raíz; no existía `ProjectOps/`.

HECHO: el plan legacy ya contenía P-001 para reconstruir el plan específico mediante auditoría. Esta intervención ejecuta esa deuda en lugar de crear una fase paralela.

#### H2 — Identidad propia

HECHO: README/package/source describen ABOS como Autonomous Business Operating System y runtime autónomo persistente/económico, no como predictor ni agente Android de misiones.

HECHO: `constitution.md` declara Never harm > Earn your existence > Never deceive. Esa constitución del producto no debe confundirse con el protocolo de desarrollo ProjectOps.

#### H3 — Adaptive Path es semántica central ABOS

HECHO: `docs/ADAPTIVE_PATH_INTELLIGENCE.md` formaliza objective != method, UNKNOWN != IMPOSSIBLE, novelty/equivalence, evidence, capability resolution y environments abiertos.

Decisión: la nueva reasoning layer debe reforzar esta semántica en lugar de importar gates científicos o Android-specific.

#### H4 — Autoridades únicas han sido un patrón reciente

HECHO por historial de PRs: cambios recientes eliminaron duplicidades o falsas autoridades en wake persistence, executor fallback, inference budget, model routing, config integrity, child health y funding recall.

Decisión: “one authority per concern” se convierte en invariante explícito de ProjectOps ABOS.

#### H5 — Economía requiere causalidad

HECHO: PR #29 está abierto y documenta que parent funding/history no equivale a live child balance/revenue/profitability.

Decisión: ProjectOps no puede tratar ese PR como integrado; P-003 queda PARCIAL y es el siguiente trabajo recuperable.

#### H6 — Drift documental real

HECHO: `src/state/schema.ts` declara `SCHEMA_VERSION = 14`.

HECHO: `ARCHITECTURE.md` conserva texto que describe migraciones v1→v8.

Decisión: registrar P-004 para reconciliación documental posterior, sin tocar runtime durante este cutover.

#### H7 — CI no es LIVE

HECHO: CI actual valida Node 20/22, typecheck, build, tests, security, Windows y distribución pública.

HECHO histórico: PR #16 dejó human ChatGPT OAuth LIVE fuera de CI; PR #13 dejó AWS billable LIVE fuera de CI.

Decisión: evidence ladder E0–E7 y P-005 para acceptance externa; no fabricar PASS.

#### H8 — ABOS es público

HECHO: repo visibility observada PUBLIC.

Riesgo: copiar literalmente la política PRIVATE_TRACKED_MATRIX de hosts privados expondría una contradicción y podría incentivar secrets en Git.

Decisión: `PUBLIC_TRACKED_DOCUMENTARY_MATRIX`. ProjectOps trackeado contiene solo reglas/baseline/plan/continuidad publicables. Estado runtime/sensible permanece fuera.
