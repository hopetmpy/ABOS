#### Hipótesis v12.12.0 — descartada por distribución

Se identificó `v12.12.0` en releases upstream con soporte Node 24 y prebuilds, pero el probe reproducible `34783482130` falló con:
`ERR_PNPM_NO_MATCHING_VERSION`.

El registro npm actual muestra que `12.12.0` no está publicado. Por tanto una release GitHub no instalable desde el package registry canónico no puede ser dependency authority de ABOS.

#### Candidato actual — v12.11.1

- declara Node `20.x || 22.x || 23.x || 24.x || 25.x || 26.x`;
- conserva `prebuild-install || node-gyp rebuild --release`;
- pertenece a la línea pre-N-API con artefactos prebuilt publicados.

Decisión actual `DECISION_READY`:
- Node 22 default/recommended;
- Node 24 segunda LTS a validar;
- `better-sqlite3@^12.11.1` como candidato de distribución normal;
- no v13 mientras Windows 24 requiera compilación en el fresh-install observado;
