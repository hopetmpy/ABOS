## Objetivo cerrado

Reconciliar las piezas cognitivas ya existentes para que una sola authority lógica gobierne memory/context activation y el working set del runtime principal, sin crear otra memoria, sin prompt masivo y sin cerrar taxonomías futuras.

## Findings resueltos

1. `MemoryRetriever` ya era la primitive correcta de cinco tiers durables: working, episodic, semantic, procedural y relationship memory. Reemplazarlo por `EnhancedRetriever` habría perdido esos tiers.
2. `ContextManager` existía con budget/tokenization/compression pero no gobernaba el main turn path. Se reutilizó y extendió; no se creó un segundo cognitive manager.
3. `KnowledgeStore` estaba cerrado sólo a nivel de tipos/aplicación. SQLite ya persistía `category` como `TEXT`; no se abrió una migration innecesaria.
4. `EnhancedRetriever` usaba category hints como filtros duros. Se corrigió para búsqueda open-world y ranking por hints.
5. Retrieval feedback vivía en globals de módulo y podía contaminar agentes/DBs. Se volvió instance-scoped.
6. Adversarial review detectó un gap real de protocolo: tool-call-only turns podían perder el assistant/tool_calls precedente. `ContextManager.renderTurn()` fue corregido y se añadió regresión.
7. `MemoryIngestionPipeline` ya es un producer material: alimenta los cinco tiers y, para señales verificables apropiadas, `knowledge_store` con source/confidence/recency, contradicciones y pruning. No se creó un extractor paralelo.
8. P-013 Evidence Fabric conserva correlation/causation/provenance; P-022 conserva futura authority de world model/beliefs. P-020 no absorbió esas responsabilidades.
