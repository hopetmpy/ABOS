## Arquitectura decidida

1. Nueva authority persistente E-xxx bajo intelligence/state, no una segunda world/adaptive/evidence authority.
2. Registro canónico de experiment metadata + variables/provenance + simulator/version + mode + seed/config + budgets + lifecycle + result/lesson/decision impact.
3. Runs persistidos por índice con seed derivada/version exacta para replay/restart/idempotencia.
4. Counterfactual = experimento derivado enlazado al E-xxx base; variables no alteradas permanecen invariantes y overrides conservan provenance.
5. Evidence sólo emite eventos referenciales con epistemic status `inference` para resultados simulados; jamás `observation` por ejecución de simulator.
6. Calibration posterior sólo acepta una Evidence explícitamente `observation`; almacena comparación derivada + evidence ID, no promueve simulation a LIVE.
7. Budget preflight antes de cada run; no late overrun por persistir después del coste.
8. Registry de simulators exacto `id + version`; replay sin fallback silencioso a otra versión.
9. Workspace no recibe ToolContext/Environment executors/Policy bypass. Esto evita un bypass provisto por el workspace, pero no se interpreta como sandbox universal para código arbitrario registrado como simulator.
10. P-025 decidirá cuándo/por qué usar la capacidad dentro de Strategic Cognition; P-024 no adelanta esa policy.
