## Objetivo

Hacer que un servidor MCP sea una mano real: descubrir/establecer transporte compatible, obtener capabilities/schemas, ejecutar calls reales, observar resultados/errores, verificar funcionalidad y registrar evidencia en Capability Fabric.

## Estado observado

La auditoría encontró una ruta donde instalar/registrar un MCP no demuestra un handshake/call MCP real y un executor puede devolver texto nominal. El objetivo no es eliminar MCP, sino completar la capacidad.

## Arquitectura objetivo

MCP adapter encapsula transports soportados por la versión vigente del protocolo al ejecutar este P. Debe existir lifecycle separado entre discovered, configured, connected/discovered, probed, verified, degraded/unavailable. `tools/list`/equivalente y call reales se transforman a descriptors del P-014 sin hacer de MCP una autoridad paralela.

## Reglas de actualidad

La especificación MCP puede cambiar. Antes de implementar, verificar documentación oficial/SDK vigentes; no codificar desde recuerdos de esta planificación. Preferir SDK/protocolo oficial compatible con Node soportado cuando reduzca riesgo.

## Security/authority

- servidor local/remoto conserva provenance;
- auth/credentials no se guardan en ProjectOps;
- tool effects/permissions se policy-checkean antes de call;
- supply-chain y endpoint trust se evalúan antes de activation;
- un servidor no puede autodeclararse trusted/verified.

## Failure matrix

Transport crash, malformed schema, server hangs, auth expired, partial output, side effect timeout, reconnect/restart, tool list changes, duplicate tool names, protocol/version incompatibility.

## Validación

Fake deterministic server para protocol tests + al menos un servidor MCP real autorizado para integration cuando sea posible; call real con input/output schema; disconnect/reconnect; negative auth; timeout/cancel; restart.

## Definition of Done

ABOS puede conectar a un MCP, descubrir al menos una tool real, policy-checkearla, llamarla, validar su respuesta y registrar la capability como verified sólo después del probe/call correspondiente.
