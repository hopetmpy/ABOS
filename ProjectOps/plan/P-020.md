## Objetivo

Convertir las piezas cognitivas existentes en una sola authority lógica que permita amplio conocimiento persistente con un working set pequeño y relevante. No crear otra memoria.

## Arquitectura integrada

- `MemoryRetriever` conserva los cinco tiers durables: working, episodic, semantic, procedural y relationship memory.
- `ContextManager` gobierna el assembly del main turn path con budget/model context y preservación de protocolo.
- `EnhancedRetriever` activa `knowledge_store` de forma suplementaria y open-world; categorías conocidas son hints de ranking, no frontera cerrada.
- retrieval feedback queda por instancia, no en globals cross-agent.
- `MemoryIngestionPipeline` conserva los producers reales de memory y knowledge.
- P-013 Evidence Fabric conserva provenance/correlation; P-022 conserva future World Model authority.
- no se añadió segunda persistence ni migration para categorías abiertas porque SQLite ya usa `TEXT`.

## Invariantes satisfechos

- ningún wiring pierde los cinco memory tiers;
- categorías nuevas no quedan invisibles por un enum de aplicación;
- assistant tool-call y tool result permanecen juntos, incluso con assistant content vacío;
- pending input sigue siendo el input final del turno;
- anti-repetition se conserva;
- restart recupera cognition durable desde SQLite sin requerir prompt histórico masivo;
- stale/expired knowledge no se activa como vigente;
- conflictos no sobreescriben silenciosamente evidence previa.
