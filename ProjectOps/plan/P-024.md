## Objetivo

Permitir que ABOS explore escenarios baratos antes de gastar dinero, ejecutar efectos irreversibles o consumir mucha inferencia: simulaciones deterministas/estocásticas, replay, what-if, counterfactuals, self-play cuando tenga sentido y experimentos E-xxx persistidos.

## Principio de eficiencia

El modelo razona/estructura la simulación una vez; código ejecuta cientos/miles de variantes; el modelo recibe estadísticas/sorpresas seleccionadas. No usar miles de llamadas LLM cuando una función/replay puede explorar el espacio.

## Registro E-xxx

Question, hypothesis, variables, parameter provenance, simulator/version, seed si aplica, cost budget, expected information gain, runs, summary, surprises, result, lesson y decision impact.

Parameter provenance: OBSERVED / ESTIMATED / INFERRED / ASSUMED / UNKNOWN + confidence cuando sea justificable.

## Invariantes

- simulator != real world; no promover simulation a LIVE;
- reproducibilidad mediante seed/version/config cuando corresponda;
- model assumptions visibles;
- experiments no pueden ejecutar side effects reales sin policy.

## Arquitectura decidida

- E-xxx tendrá authority persistente propia bajo intelligence/state.
- Adaptive paths y World Model son inputs/correlation/consumers, no owners del experimento.
- Evidence Fabric referencia E-xxx y mantiene causalidad; resultados simulados se registran como `inference`, no `observation`.
- simulator registry exige `id + version` exactos; no existe fallback silencioso durante replay.
- runs persistidos e indexados permiten restart/resume/idempotencia.
- counterfactuals son experimentos derivados que conservan variables base salvo overrides explícitos con provenance.
- budget se valida antes de ejecutar cada run.
- calibration simulado→real sólo se acepta contra Evidence externa con epistemic status `observation` y conserva el evidence ID.
- Workspace no posee ToolContext ni executors externos; policy/capability/environment siguen siendo la única frontera para side effects reales.
- la selección estratégica de cuándo simular pertenece a P-025; P-024 expone una capacidad consumible y verificable sin adelantar Strategic Cognition v2.

## Validation

Replay determinista, stochastic reproducibility, counterfactual consistency, budget enforcement y comparación posterior simulado→real para calibrar el simulator. Además: fresh/upgrade schema, restart/resume sin duplicate runs, exact-version/no-fallback, idempotencia, simulated evidence `inference`, calibration que rechaza no-observation y partial-failure adversarial.

## Definition of Done

ABOS puede decidir “simular antes de actuar”, ejecutar múltiples escenarios de bajo coste y usar el resultado como evidencia E0–E4 apropiada sin confundirlo con observación externa.

Interpretación de frontera: P-024 hace real, persistente y consumible el workspace; P-025 posee la política estratégica que decidirá automáticamente cuándo invocarlo dentro del plan/review adaptativo.
