## Objetivo

Demostrar que ABOS no son subsistemas aislados sino una sola trayectoria causal y recuperable:

OBJECTIVE → activate context → beliefs/world model → alternatives → predict/simulate → decide/review → authority/policy → resolve capability → choose environment/actor/model → execute → observe → evaluate outcome → learn/update memory/skill → economic accounting → continuity/next objective.

## Scenarios mínimos

1. tarea resoluble con capability ya verificada;
2. capability gap → acquire/construct → probe → use;
3. task requiring browser/computer hands;
4. provider/environment route failure → evidence → explicit replan;
5. task delegated a child/worker;
6. economic experiment with cost/outcome accounting;
7. restart mid-work with no duplicate side effect;
8. inference escalation/deescalation with cognitive cost evidence.

Mocks son válidos para determinism de componentes; al menos E4 realista debe cruzar las autoridades principales. External LIVE se registra en P-005.

## Definition of Done

Los escenarios E2E pasan con correlation evidence, persistence/restart cuando aplica y sin manual glue entre subsistemas; no quedan claims de “integrado” sustentados sólo por unit tests.
